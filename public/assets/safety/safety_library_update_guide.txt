# SAFETY LIBRARY - CONTENT UPDATE GUIDELINES
==============================================

This guide helps you update the Safety & Tools Library dynamically without changing any application code.

## 1. WHERE IS THE DATA?
The data is stored in your Supabase project in the 'safety_library' table. 
You can access it via your Supabase Dashboard.

## 2. UPDATING IMAGES
You have two ways to add images:

### Option A: Using Google Drive (Recommended)
1. Upload your image to Google Drive.
2. Right-click File -> Get Link.
3. Set access to "Anyone with the link can view".
4. Copy the link (e.g., https://drive.google.com/file/d/1A2B3C.../view).
5. Paste this link into the 'images' array in the Supabase table.

### Option B: Local Assets
1. Copy the new image files into this folder (public/assets/safety/).
2. Note the filename (e.g., gloves_new.webp).
3. Add the path in the Supabase 'images' array: ["/assets/safety/gloves_new.webp"]

## 3. DATABASE FORMAT (Supabase UI)
When editing the 'images' column for a row, use a JSON array format.
- Single image: ["link1"]
- Multiple images: ["link1", "link2", "link3"]

The first image in the list will be the primary image displayed.
