# SAFETY LIBRARY — CONTENT UPDATE

Identify (Safety Library) is an in-app catalog. It does not read a live Google Sheet.

## Where is the data?

`src/data/safetyLibraryItems.js`

Each item has: id, category, name_bn, function_bn, images[], approx_price_inr, guide_bn, related_items[].

## Images

1. Copy files into `public/assets/safety/` (or `public/assets/safety/library/<category>/`).
2. Run `node scripts/maintenance/compress-safety-library-images.mjs` so they stay phone-sized WebP.
3. Add the public path to that item's `images` array, e.g. `"/assets/safety/library/ppe/helmet.webp"`.

The first image is the grid thumbnail source (a random image from the list is shown on cards).

Native APK loads these from the live website, not from Drive.
